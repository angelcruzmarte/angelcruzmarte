## Overview

This PR delivers a **book discovery upgrade** for VOXYFI and adds **graceful AI Gateway rate-limit handling** to the reading assistant. All existing behavior is preserved — the Amazon Associates affiliate flow, AI features (summaries/quizzes), authentication, and the existing bookstore are untouched.

> Note on scope: `main` was significantly behind this active v0 development branch, so merging this PR also brings prior accumulated app work into `main`. The summary below focuses on the most recent discovery-upgrade changes, which are the substance of this session.

## What's new

### 1. Personalized discovery rows
- `Continue Reading`, `Recommended For You`, and `Because You Read {Title}` rows built from real purchase history and saved interests for signed-in users.
- Graceful fallback to curated rows for signed-out/new users (no empty states).

### 2. Classic Literature collection
- A dedicated, hourly-rotated **"Classic Literature"** row surfacing the public-domain catalog.
- Named accurately: the catalog's public-domain titles are paid ($3.99–$6.99), so they are **not** labeled "Free" — the section is presented honestly as "Classic Literature."

### 3. AI-enriched detail pages
- "About this book" summary, themes, difficulty, and author note — generated once and **cached on the book row**, so viewing never consumes the AI quota.
- Word-count-based reading/listening time estimate.
- Same-genre **Similar Books** rail.

### 4. VOXYFI ratings for every book
- First-party ratings for all books, including affiliate titles. Amazon stays purchase-only; ratings never link out to Amazon.
- Aggregate is hidden below 3 ratings ("Not enough ratings yet"); at >= 3 it shows the mean and count. The signed-in user always sees their own rating.

### 5. "Ask VOXYFI" reading assistant
- Floating assistant that recommends **only real catalog books** via server-side tool calling — deep-links to detail pages, never touches checkout.
- Shares the same free-tier AI token bucket as other AI tools; the token is spent only on a successful answer, so failed requests stay free.

### 6. Graceful AI Gateway rate-limit (HTTP 429) handling  (requested in this session)
- Assistant errors are classified as `quota` | `rate_limit` | `error` and returned as a structured `{ kind, error }` payload from both the pre-stream quota guard and streaming failures.
- AI Gateway 429s are detected via `APICallError.statusCode` and message heuristics; **no raw provider/stack text is ever shown to the reader**.
- On a rate limit, the client **auto-retries once** after a short backoff (friendly "retrying in a moment..." state), then surfaces a clear message with a manual **"Try again"** button.
- The "See premium" upgrade link is scoped to the **quota** case only.

## Data / schema changes
- Added `book_rating` table (userId, bookId, stars).
- Added additive `book` enrichment columns: `aiSummary`, `aiThemes`, `aiDifficulty`, `aiReadingLevel`, `aiAuthorNote`, `aiEnrichedAt`. No data loss.

## Notable fix
- The assistant's `searchCatalog` tool treated the model's optional `category` arg as an exact match (`category = 'fiction'`), which zeroed out results because real categories are values like "Historical Fiction". Reworked to tokenized partial matching across title/author/category/description with relevance ranking (verified: "Jane Austen" + "fiction" went 0 -> 191 matches).

## Verification
- `tsc --noEmit` clean; `next build` succeeds.
- Browser-verified at 440px mobile and 1280px desktop with an authenticated session:
  - Discovery rows, enrichment, reading-time, Similar Books render.
  - Ratings: confirmed both the "< 3 ratings hidden" and ">= 3 aggregate shown (4.7 / 3 ratings)" states, plus persistence.
  - Assistant returns real catalog books (e.g. mystery -> *A Study in Scarlet*, *The Secret Adversary*).
  - Rate-limit UX: confirmed friendly message, one automatic retry, and the manual "Try again" button (temporary simulation used for the test, then removed).

## Operational note
- The AI Gateway free tier rate-limits the shared model, so under heavy use the assistant/enrichment can hit 429. This PR makes that experience friendly and self-recovering; adding AI credits removes the limit entirely. This is a plan constraint shared with the existing summary/quiz features, not a defect.
